# 火腿饭团的做法

![火腿饭团](./饭团.png)
一道简单快手的日式风味饭团，咸香火腿搭配沙拉酱与海苔，口感丰富饱腹。富含碳水化合物、蛋白质和维生素，能快速补充能量。制作难度极低，新手也能轻松上手，从煮饭到完成大约只需 1 小时。

预估烹饪难度：★★★★

预估卡路里：665 大卡

## 原料

当前 1 份量约 2 人，制作前需要确定计划做几份。

每份：

| 食材 | 用量 | 分组 | 备注 |
| --- | --- | --- | --- |
| 火腿 | 100g |  |   |
| 米饭 | 125g |  |   |
| 水 | 90ml |  |   |
| 喜欢的沙拉酱 | 20g |  | 推荐日式 mayo！ |
| 食用油 | 10-15ml |  |   |
| 青豆 | 30g | 可选 | 冷冻青豆 |
| 玉米 | 30g | 可选 | 冷冻玉米粒 |
| 海苔碎 | 10g | 可选 |   |

## 操作

1. 将米饭和水放到电饭锅里，点击米饭模式，等待完成
2. 冷冻玉米粒和青豆放到锅里，加水没过所有食材，沸腾后静待 2 分钟后，捞出。
3. 火腿切成 1cm 的方块
4. 与此同时，加入 10ml 食用油，加入火腿翻炒至火腿上色
5. 将米饭，火腿，海苔碎，青豆，玉米粒，沙拉酱放入碗中，混合均匀即可
6. 装盘（如果有的话）

## 附加内容

- 沙拉酱的程度可以根据个人口味酌情删减。
- 可以尝试混合沙拉酱。
